👨‍💻 Projetos Práticos de Machine Learning

Este repositório reúne meus projetos e estudos práticos em Machine Learning, com foco em aplicações reais e desafios propostos nos diferentes cursos que realizo sobre o tema. Cada notebook aborda um tema específico — desde estatística até sistemas de recomendação — com uso de ferramentas modernas e código comentado.

🧠 Tópicos Abordados

Classificação e Regressão

Clustering e Análise de Similaridade

Séries Temporais (incluindo ARIMA e decomposição)

Otimização com Hiperparâmetros

Redução de Dimensionalidade

Processamento de Linguagem Natural (NLP)

Sistemas de Recomendação


⚙️ Tecnologias Utilizadas

Python (Pandas, Scikit-learn, Keras, Statsmodels)
Jupyter Notebook
Matplotlib & Seaborn para visualização
